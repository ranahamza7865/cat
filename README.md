# FELINE — The Art of Cats

A cinematic, ultra-realistic 3D website dedicated to beautiful cats, designed to feel like an award-winning Awwwards/Apple-level interactive experience.

## ✨ Features

### Hero Section
- Full-screen immersive 3D environment with a realistic white Persian cat
- Cinematic golden hour lighting with volumetric effects
- Floating particles animation
- Mouse-based parallax effects
- Interactive cat that subtly moves its head and eyes with mouse movement
- Subtle breathing and blinking animations

### 3D Interactions
- Smooth GSAP animations with ScrollTrigger
- Three.js powered 3D scene with realistic cat models
- Mouse parallax effects with depth perception
- Scroll-based camera transitions
- Responsive 3D interactions for desktop and mobile

### Cat Collection
Showcases 6 beautiful cat breeds:
1. **Persian** - Luxurious long coat, gentle expression
2. **Maine Coon** - The gentle giant, water-loving
3. **Bengal** - Jungle spotted marvel, wild beauty
4. **Ragdoll** - Possessed of an uncanny calm
5. **British Shorthair** - Dense coat, round face, regal bearing
6. **Siamese** - Vocal personality, striking contrast

Each breed card features:
- Large, beautiful, realistic visuals
- Interactive hover animations
- Smooth transitions on selection

### Interactive Cat Experience
- Full 3D interactive cat model
- Mouse movement influences head direction
- Click to trigger cute reactions
- Real-time blinking and tail movement
- Floating sparkle effects

### Gallery Section
- Premium editorial layout
- Multiple image sizes with staggered grid
- Elegant typography overlay
- Smooth hover effects with scale animations

### Final Section
- Cinematic full-screen cat portrait
- Gradient overlay with elegant typography
- "Explore the Collection" button with magnetic effect

## 🛠️ Installation

```bash
cd feline-website
```

Open `index.html` in your browser. For best experience:
- Use a modern browser (Chrome, Firefox, Safari, Edge)
- Enable WebGL
- Use a computer with decent GPU

## 🎯 Usage

1. Open `index.html` in a modern browser
2. Wait for the preloader
3. Scroll down to explore:
   - Hero section with 3D Persian cat
   - Breed collection grid
   - Interactive 3D cat experience
   - Cinematic gallery
   - Final cinematic section

## 🔧 Customization

- Replace placeholder images in `assets/images/` with high-quality cat photography
- Adjust color variables in `:root` in `css/style.css`
- Modify animation timings in `js/main.js`
- Change font sizes in responsive media queries

## 📝 Notes

- Images use Unsplash as placeholder; replace with dedicated cat photography
- 3D models are simplified representations - realistic textures would enhance realism
- All animations respect `prefers-reduced-motion` for accessibility
